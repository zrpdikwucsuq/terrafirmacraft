## Overview

TerraFirmaCraft is a total conversion mod for Minecraft Java Edition that replaces vanilla gameplay with a deep, realistic geology and metallurgy progression. Players must identify ore veins by rock type, smelt metals through historically accurate bloomery and crucible processes, grow crops with realistic seasons and soil nutrition, and advance from stone age through bronze, copper, and iron ages before reaching steel. Designed for long-form survival playthroughs.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Minecraft TerraFirmaCraft** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Realistic Geology** | Multi-layer stone strata with ore veins identified by geological context |
| **Historical Metallurgy** | Bloomery, crucible, and alloy smelting with accurate metal properties |
| **Soil & Farming** | Nutrient-based soil system and seasonal crop growth calendar |
| **Technology Ages** | Progression from stone tools through bronze, copper, iron, and steel |
